# Bài thi thực hành Python - Đề số 09

## Các file

- `cau1.py`: quản lý điểm học tập trên console.
- `cau2.py`: giao diện quản lý điểm học tập bằng Tkinter.
- `cau3.py`: đọc CSV, thống kê, vẽ biểu đồ và xuất cảnh báo.
- `du_lieu_09.csv`: dữ liệu mẫu theo đề.

## Cách chạy

```powershell
python -m pip install -r requirements.txt
python cau1.py
python cau2.py
python cau3.py
```

Sau khi chạy `cau3.py`, chương trình tạo `bieudo.png` và `canh_bao.csv` trong cùng thư mục.
